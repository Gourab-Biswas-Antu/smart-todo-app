## 📖 Overview

**Smart To-Do App** is a lightweight, browser-based task manager. It lets you quickly add tasks, mark them as complete, filter your list by status, and clear completed items — all with a clean, distraction-free interface.

## 🛠️ Tech Stack

- **HTML5** – structure
- **CSS3** – styling and layout
- **JavaScript (Vanilla)** – app logic and DOM manipulation

## ✨ Features

- ➕ Add new tasks instantly
- ✔️ Mark tasks as active or completed
- 🔍 Filter tasks by **All / Active / Completed**
- 🗑️ Clear all completed tasks in one click
- 🔢 Live count of remaining items
- 📱 Responsive, minimal UI

## 📦 Dependencies

This project uses **no external libraries or frameworks** — built entirely with vanilla HTML, CSS, and JavaScript.
